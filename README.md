# Sales Performance Analytics Dashboard

## Project Overview
This project analyzes sales performance data using Excel, Python, SQL, and Power BI.

## Dataset Columns
- Order ID
- Order Date
- Customer
- Region
- Product
- Sales
- Cost
- Profit
- Year
- Month

## Tools Used
- Excel
- Python (Pandas)
- SQL
- Power BI

## Project Workflow
1. Data understanding using Excel
2. ETL process using Python
3. SQL analysis for insights
4. Dashboard creation in Power BI

## Dashboard Features
- Monthly Sales Growth
- Region-wise Analysis
- Product Performance
- Sales and Profit KPIs

## Key Insights
- Identified profitable regions
- Analyzed monthly sales growth
- Compared product performance
